# Bounded moderation cleanup

`purgepreview channel count` inspects at most10 latest messages, not10 eligible messages from an unbounded history. Selects only native exact IDs with current server/channel identity,not pinned/not system,under13days. Stores server/channel/staff/message IDs and time,never contents. Private preview displays exact IDs,not message bodies. No deletion. Up to50 pending previews/server,stale previews pruned after24hours on next preview.

`purgeconfirm plan-id confirm:true` uses only caller-owned same-server preview,no arbitrary IDs. Expires2minutes. Fetch each exact message with force/cache:false; any missing,unreadable,foreign,pinned,system,aged message stops without deleting. Refresh channel and actor/bot permissions again. Mark executing and write case before native exact-array delete. No replacement messages; no auto retry after uncertainty or restart. Claimed previews become uncertain on restart rather than executing again. Completed/uncertain history currently persists until operator-managed retention,not advertised as automatic full cleanup.

Official references: https://docs.discord.com/developers/resources/message and https://docs.discord.com/developers/resources/channel. Full official deletion-section retrieval and real endpoint validation remain release gates.
