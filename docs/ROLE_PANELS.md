## Scoped panel shutdown and private mapping export

`/reactionroles disablechannel channel-id confirm:true` disables active stored panels bound to one exact channel ID. `/reactionroles disablerole role-id confirm:true` disables entire active panels containing one role in any button mapping,including multi-button panels. Whole-panel shutdown also stops its other role buttons. IDs can refer to departed resources because this only changes stored active bindings,no native mutation. Pending/uncertain records stay untouched;role assignments,button mappings,click receipts and native messages remain. In-flight clicks can finish. Repeating is a no-op.

`/reactionroles export` returns a private UTF-8 JSON snapshot of the latest100stored panels and their complete ordered button mappings,with total/truncated fields. Channel/message/role IDs and button text are sensitive configuration;keep private. No staff/member IDs,click receipts,interaction source IDs or live readiness claims. Not a full backup/import format. All three require fresh native ManageRoles actor identity,private3locale embeds,no mentions. Three tests cover full multi-panel shutdown scope,status/isolation/receipts,export bounds/content,and confirmation/current manager/localized attachment bytes. No live/native message or client visual verification.
