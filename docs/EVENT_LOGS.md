No message-delete/edit contents, role/channel overwrite bodies, names, profile text or guessed actor attribution. IDs and event kind only. Partial message update events are not handled.

Configuration now checks current Manage Server on every command, not only interaction snapshot. Defaults events empty, preserving existing case-only behavior. ## Preview and stop disclosure

`preview` privately shows a sample case-log payload using the caller ID. No destination lookup/native send/reservation/config change. It does not certify audience privacy or channel/runtime readiness.

`pauseevents confirm:true` clears all8metadata event selections,keeps case-log master enabled state/destination and receipt guards. `reset confirm:true` sets master disabled,forgets destination and clears event selections. No native log messages/cases/receipt erasure. Other guild/locale/welcome config unchanged. Both fetch exact current ManageGuild and require explicit confirmation;runtime flags need not be enabled to stop. Already-sent/in-flight logs cannot be recalled. Pending metadata sends recheck latest consent/destination after native validation,finish reserved receipt unavailable when opt-out changed,never retry. This does not guarantee atomic recall after finalcheck. All replies private localized/no-ping shared embeds,not live/client visual acceptance.
